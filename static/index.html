🎓 How This Tool Works & Beginner's Guide to GitHub

Master computer networking, port security, and how to publish your code to GitHub cleanly.

1

What is a Port Scanner and how does it work?

Every computer communicates across a network using IP addresses (like your home address) and Ports (numbered 1 through 65,535, like apartment numbers). A port scanner performs a TCP 3-way handshake:

Client -> [SYN] -> Server Server -> [SYN-ACK] (Port is OPEN!) Server -> [RST] (Port is CLOSED / OFF)

PortSentinel uses Python's non-blocking socket interface with multi-threading to check hundreds of ports concurrently in seconds.

2

What are "Secret Connections"?

Malware, spyware, telemetry scripts, or unauthorized background processes often open outbound sockets to remote IP addresses. PortSentinel inspects the operating system's internal connection table (via netstat and PID resolution) to identify the exact .exe process name responsible for each connection.
